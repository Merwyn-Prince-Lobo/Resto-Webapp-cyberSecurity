About This Training Lab

Challenge: Can you exploit the SQL injection vulnerability in this endpoint?

Learning Objectives:

  • Understand how SQL injection works
  • Learn to identify unsafe database queries
  • See how trap mechanisms can detect exploitation
  • Review security logging and monitoring
  • Compare unsafe vs. parameterized queries

Safe Patterns (Like the Rest of the App):

# ✅ SAFE - Parameterized Query
cursor.execute("SELECT * FROM coupons WHERE code = ?", (user_input,))

# ❌ UNSAFE - String Concatenation (This endpoint)
query = f"SELECT * FROM coupons WHERE code = '{user_input}'"
cursor.execute(query)

Hidden Database Table:

There is a hidden table in the database not referenced in the UI: secret_coupons

Can you find it and retrieve records using SQL injection? A trap coupon awaits!
